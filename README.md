# Content Detect

转发前，把内容与你的账号方向对照一次。

Chrome Manifest V3 扩展，使用 [TypeSafe Jev](https://typesafe.ai/) 判断当前页面是否适合转发到自己的账号，同时分析 AI 生成迹象、内容情绪，以及快乐幽默、知识、共鸣、节奏四项内容价值。你提供 API key，用自然语言描述受众、主题、表达偏好和不想分享的内容。

## 安装与首次使用

目前通过 Chrome 的「加载已解压的扩展程序」安装本地构建。

### 1. 准备环境

- Chrome 120 或更新版本。
- Node.js 22 或更新版本，以及 npm。在终端运行 `node --version`、`npm --version` 确认已安装。
- Git 和本仓库的访问权限，用于下载与更新源码。
- 自己的 [TypeSafe API key](https://console.typesafe.ai/)，在首次使用时填写；安装和构建不需要 Key。

### 2. 下载并构建

在终端执行：

```sh
git clone https://github.com/zkhCreator/content-detect.git
cd content-detect
npm ci
npm run build
```

如果已经有项目源码，直接在项目根目录执行最后两条命令即可。构建成功后会生成 `dist/chrome` 目录，其中包含 `manifest.json`。构建完成即可关闭终端，使用插件不需要一直运行开发服务。

### 3. 加载到 Chrome

1. 在 Chrome 地址栏输入 `chrome://extensions` 并打开。
2. 打开页面右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择项目内的 **`dist/chrome` 文件夹**，不要选择项目根目录、`dist` 目录或单独的 `manifest.json` 文件。
5. 确认扩展列表出现「Content Detect · 转发方向检查」，且开关已启用。
6. 点击 Chrome 工具栏的拼图图标，在扩展列表中固定 Content Detect，方便随时打开。

请保留该构建目录；Chrome 会从所选目录加载插件文件。

### 4. 配置并检查内容

1. 打开一篇普通网页文章，点击工具栏上的 Content Detect 图标。
2. 进入「账号设定」，填写自己的 Jev API key 和账号方向，点击「保存账号设定」。
3. 回到「内容检查」，点击「检查当前页」。选中文字时优先检查选区；未选择时提取正文。打开弹窗本身不产生请求。
4. 查看转发建议、AI 生成判断、情绪与四项内容价值，并结合五项适配判断决定是否分享。「查看模型概率」展开分类分布；「查看 0–4 分标准」展开四要素的具体标准。

示例账号方向：

> 面向独立开发者，分享 AI 产品、开发实践和真实创业经验。偏好具体、克制、有方法的内容；不转发夸大收益、纯营销或无依据的预测。

不要将 Key 放进代码、终端命令、`.env`、截图或 Git 提交。Key 只需在插件界面输入。

### 更新已安装的插件

在项目根目录执行：

```sh
git pull --ff-only
npm ci
npm run build
```

然后打开 `chrome://extensions`，点击 Content Detect 卡片上的刷新按钮，再重新打开插件。沿用原安装目录即可，无需先卸载；卸载会清除已保存的设定。

### 常见安装问题

| 问题 | 处理方法 |
| --- | --- |
| 终端提示找不到 `node` 或 `npm` | 安装 Node.js 22+ 后重新打开终端，再检查版本 |
| 找不到 `dist/chrome` | 确认在项目根目录执行了 `npm ci` 和 `npm run build`，且构建没有报错 |
| Chrome 提示缺少或无法加载清单文件 | 选择包含 `manifest.json` 的 `dist/chrome` 文件夹 |
| 修改代码后插件没有变化 | 重新运行 `npm run build`，并在扩展管理页刷新插件 |
| 提示当前页面无法读取 | 切换到普通 HTTP/HTTPS 网页；浏览器设置页、扩展商店页和 PDF 可能不支持 |
| 提示 API key 无效或没有访问权限 | 在「账号设定」中替换 Key 并保存，再手动检查 |

## 看懂结果

| 结果 | 含义 |
| --- | --- |
| 适合转发 | 主题、受众价值和表达各项支持概率超过 70%，边界冲突低于 30%，且上下文充分 |
| 建议先复核 | 至少一项不确定，或文字不足、提取被截断、未找到独立正文 |
| 不建议转发 | 上下文充分时，存在明确的方向冲突或明显不适配的维度 |

五个维度的百分比都是 Jev 对某个条件成立的概率。**边界冲突越低越好**。不是内容质量分、转发成功率，也不是整次判断的「准确率」。判断依据由本地规则汇总，未伪装成模型生成的解释。阈值是第一版产品策略，尚未用你的账号样本校准。

每次手动检查最多一次请求；出错后由用户主动重试。关闭弹窗后后台继续，重新打开可看最近结果。只保留一个最近检查；改变账号设定、标签导航或关闭目标标签会清除旧结果。会话结果不是内容历史记录，同页动态变化或新选区需要点击重新检查。

### AI 生成判断与内容情绪（0.2.0）

| 分析项 | 展示内容 |
| --- | --- |
| AI 生成判断 | 疑似 AI 生成、偏向人工写作、无法判断 |
| 情绪倾向 | 正面、中性、负面、正负混合、无法判断 |
| 主要情绪 | 平静／客观、喜悦／兴奋、期待／鼓舞、愤怒／不满、悲伤／失落、担忧／焦虑、惊讶、多种情绪交织、其他情绪、无法判断 |

三个分析使用 Jev Choice；当前版本与五个 Noul、四个 Score 合并为**一次请求、十二个问题**。输入字段和浏览器权限不变；新增问题会增加输入 token，不代表费用不变。

**AI 来源判断只是文本迹象推断，不能证明内容由谁创作。** 列表结构、语法工整、专业表达或谈论 AI 本身不应直接视为 AI 证据。改写、翻译和人机混合创作尤其难区分。情绪分析描述文字表达，不推断作者的真实心理或健康状况，也不把报道负面事件等同于负面情绪。

每项结果的模型置信度低于 `0.6`、首选项概率低于 `0.65`，或模型选择不确定时，界面显示「无法判断」。现有上下文不足时三项均不做明确分类；少于 200 字符的文本不做明确 AI 来源归类，但仍可分析情绪。这些是保守的产品默认规则，并非经过真实数据验证的准确率保证。可展开查看原始概率与置信度，置信度表示选项分布的集中程度。

新分析独立展示，不因疑似 AI 或负面情绪自动否决转发。原有五维判断仍按你填写的账号方向评估；有特殊要求时，请写进账号方向。升级前的缓存结果会显示「待重新检查」，不会自动重新上传页面。

### 内容价值四要素（0.3.0）

按用户提供的「影视飓风视频四要素」框架改编为页面文字检查，不代表官方工具或官方评分。

| 要素 | 希望带来的感受 | 检查文字中的表现 |
| --- | --- | --- |
| 快乐幽默 | 看着真有意思。 | 乐趣、幽默或有回报的惊喜 |
| 知识 | 原来如此，学到了。 | 具体信息、新视角或清楚的解释 |
| 共鸣 | 我也这样，我能理解他。 | 人物处境、情绪或愿望带来的联系 |
| 节奏 | 我还想继续看。 | 铺垫、推进、揭晓，以及理解和情绪的停顿 |

四个 Jev Score 各使用五档具体标准，展示 **0–4 分**的加权位置；分数不是概率，也不是实测观众反馈。界面的「邻近评分标准」是最接近该分数的本地标准说明，不是模型引用原文生成的解释。可以展开查看所有档位。

四项互补，**不计算总分、不要求全部高分、不直接改写转发结论**。严肃的知识文章可以幽默分低而仍适合分享。低置信度（低于 `0.6`）显示「待复核」；上下文不足时不展示评分。选区、截断或整页回退时，节奏显示「无法判断」，因为提取片段不能代表完整正文的结构。

节奏只评估提取文字，不能判断视频剪辑、声音、镜头或实际完播效果。知识分也不等于事实核查，共鸣分不等于作者真实情绪或实际受众反应。这些阈值尚未经过真实语料校准。旧缓存显示「待重新检查」，升级不会自动发送页面。

## 隐私与限制

- API key 和账号方向保存在 `storage.local`，不通过浏览器同步；扩展后台限制页面注入脚本读取存储。**本地存储没有额外加密**，能访问浏览器配置或调试扩展的人仍可能读到 Key。
- 仅手动检查时，向固定的 TypeSafe HTTPS 接口发送账号方向、提取文本、标题和站点来源；Key 放在认证头。不会发送 URL 路径、参数或片段，不读取表单、编辑区、Cookie、浏览历史或其他标签页。
- 正文只存在本次请求内存中；最近结果及标题/站点/字符数等摘要暂存于 `storage.session`，不落入持久化历史。没有自建服务器、分析埋点或错误上报。
- 登录后的可见正文仍可能包含私人资料。请不要在邮件、聊天、内部文档等敏感页面发起检查。不能保证从任意网页自动识别和剔除所有个人信息。
- 最多提取 12,000 字符；长文、页面整体回退或上下文不足会显示复核。只读取主页面可见 DOM 文字，不处理 iframe、封闭 Shadow DOM、图片、音视频或 PDF，不绕过付费墙。社交动态页建议先选中一条内容。
- Jev 官方说明中文等非英文文本准确率较低。上线前应使用你的实际账号样本验证；本工具不做事实核查、授权核验或自动转发。

完整数据流、删除方式和公开仓库注意事项见 [PRIVACY.md](PRIVACY.md)。

## 开发与验证

```sh
npm run check
npx playwright install chromium
npm run test:browser
```

`npm test` 验证接口契约、判断边界、错误处理和后台生命周期。浏览器测试加载实际构建，用工具栏动作授予 `activeTab`，检查真实弹窗、内容提取和存储隔离；只使用合成网页和拦截的 API 响应，不需要 Key。截图与测试摘要写入被忽略的 `artifacts/`。

`npm run audit:privacy` 扫描工作文件、构建产物、全部可达 Git 历史和提交邮箱。它是启发式防线，不能证明所有隐私数据均不存在；提交前仍需检查 diff。个人内容不应被放入测试或文档。

目录职责、跨浏览器迁移边界见 [架构说明](docs/ARCHITECTURE.md)。实际测试范围与未验证事项见 [验证记录](docs/VALIDATION.md)。
