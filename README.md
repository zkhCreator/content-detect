# Content Detect

转发前，把内容与你的账号方向对照一次。

Chrome Manifest V3 扩展，使用 [TypeSafe Jev](https://typesafe.ai/) 判断当前页面是否适合转发到自己的账号。你提供 API key，用自然语言描述受众、主题、表达偏好和不想分享的内容。

## 安装

需要 Node.js 22+、npm 和 Chrome 120+。

```sh
npm ci
npm run build
```

1. 打开 Chrome 的 `chrome://extensions`，启用「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本项目的 **`dist/chrome`** 目录。
3. 在工具栏固定 Content Detect，打开任意普通网页。
4. 打开插件，进入「账号设定」，填写自己的 [TypeSafe API key](https://console.typesafe.ai/) 和账号方向，保存。
5. 点击「检查当前页」。选中文字时优先检查选区；未选择时提取正文。打开弹窗本身不产生请求。

示例账号方向：

> 面向独立开发者，分享 AI 产品、开发实践和真实创业经验。偏好具体、克制、有方法的内容；不转发夸大收益、纯营销或无依据的预测。

重新构建后，在扩展管理页点击刷新。不要将 Key 放进代码、终端命令、`.env`、截图或 Git 提交。Key 只需在插件界面输入。

## 看懂结果

| 结果 | 含义 |
| --- | --- |
| 适合转发 | 主题、受众价值和表达各项支持概率超过 70%，边界冲突低于 30%，且上下文充分 |
| 建议先复核 | 至少一项不确定，或文字不足、提取被截断、未找到独立正文 |
| 不建议转发 | 上下文充分时，存在明确的方向冲突或明显不适配的维度 |

五个维度的百分比都是 Jev 对某个条件成立的概率。**边界冲突越低越好**。不是内容质量分、转发成功率，也不是整次判断的「准确率」。判断依据由本地规则汇总，未伪装成模型生成的解释。阈值是第一版产品策略，尚未用你的账号样本校准。

每次手动检查最多一次请求；出错后由用户主动重试。关闭弹窗后后台继续，重新打开可看最近结果。只保留一个最近检查；改变账号设定、标签导航或关闭目标标签会清除旧结果。会话结果不是内容历史记录，同页动态变化或新选区需要点击重新检查。

## 隐私与限制

- API key 和账号方向保存在 `storage.local`，不通过浏览器同步；扩展后台限制页面注入脚本读取存储。**本地存储没有额外加密**，能访问浏览器配置或调试扩展的人仍可能读到 Key。
- 仅手动检查时，向固定的 TypeSafe HTTPS 接口发送账号方向、提取文本、标题和站点来源；Key 放在认证头。不会发送 URL 路径、参数或片段，不读取表单、编辑区、Cookie、浏览历史或其他标签页。
- 正文只存在本次请求内存中；最近结果及标题/站点/字符数等摘要暂存于 `storage.session`，不落入持久化历史。没有自建服务器、分析埋点或错误上报。
- 登录后的可见正文仍可能包含私人资料。请不要在邮件、聊天、内部文档等敏感页面发起检查。不能保证从任意网页自动识别和剔除所有个人信息。
- 最多提取 12,000 字符；长文、页面整体回退或上下文不足会显示复核。只读取主页面可见 DOM 文字，不处理 iframe、封闭 Shadow DOM、图片、音视频或 PDF，不绕过付费墙。社交动态页建议先选中一条内容。
- Jev 官方说明中文等非英文文本准确率较低。上线前应使用你的实际账号样本验证；本工具不做事实核查、授权核验或自动转发。

完整数据流、删除方式和公开仓库注意事项见 [PRIVACY.md](PRIVACY.md)。

## 开发与验证

```sh
npm run check
npx playwright install chromium
npm run test:browser
```

`npm test` 验证接口契约、判断边界、错误处理和后台生命周期。浏览器测试加载实际构建，用工具栏动作授予 `activeTab`，检查真实弹窗、内容提取和存储隔离；只使用合成网页和拦截的 API 响应，不需要 Key。截图与测试摘要写入被忽略的 `artifacts/`。

`npm run audit:privacy` 扫描工作文件、构建产物、全部可达 Git 历史和提交邮箱。它是启发式防线，不能证明所有隐私数据均不存在；提交前仍需检查 diff。个人内容不应被放入测试或文档。

目录职责、跨浏览器迁移边界见 [架构说明](docs/ARCHITECTURE.md)。实际测试范围与未验证事项见 [验证记录](docs/VALIDATION.md)。
